用 Vue3 组合式 API 重构老项目的踩坑记录
▾
📅 2026-09-12 Vue3 前端
把一个两年历史的 Options API 项目迁到组合式 API，变化的不只是写法，更是组织代码的心智模型。

接手这个项目时，同一个组件里 data、methods、watch 分散在上百行中，想改一个功能要在选项之间来回跳。重构的目标不是追新，而是让相关的逻辑重新聚拢到一起。

为什么选 <script setup>

更少的样板代码、更好的 TypeScript 推导，顶层声明直接可用于模板。一个明显的收益是：逻辑可以按功能垂直组织，而不是按选项类型水平切割。

踩过的坑

  • reactive 对象解构后会丢失响应性，需要用 toRefs 包一层；
  • ref 在模板里自动解包，但在 JS 中必须老老实实写 .value；
  • watch 监听多个源用数组形式，别忘了 flush: 'post' 才能拿到更新后的 DOM。

抽离可复用逻辑时，把函数命名为 useXxx 的组合式函数，状态的归属和生命周期立刻清晰起来。重构完成后，几个核心组件的行数少了近三分之一。

CSS 玻璃拟态（Glassmorphism）效果完全指南
▾
📅 2026-08-28 CSS 设计
半透明背景、背景模糊、细边框和柔和阴影，四个要素拼出高级感十足的磨砂玻璃卡片。

玻璃拟态的本质，是让元素模拟一块磨砂玻璃：背后的内容透过来但被模糊，边缘有一圈若有若无的高光。

四要素

  • 半透明背景：background: rgba(255,255,255,0.08)；
  • 背景模糊：backdrop-filter: blur(12px)；
  • 细边框描边，模拟玻璃边缘的反光；
  • 柔和的投影，让卡片从背景上浮起来。

两个注意点

Safari 需要 -webkit-backdrop-filter 前缀；模糊层会占用 GPU，同屏卡片过多时低端机会掉帧，建议配合内容懒加载。另外玻璃效果只在背景足够丰富时好看，纯色背景上会显得发灰。

前端性能优化：从 8 秒到 1.2 秒的实践清单
▾
📅 2026-08-15 性能优化
先测量再优化。图片、打包体积、渲染路径三管齐下，首屏加载时间的降幅可以非常可观。

优化前先用 Lighthouse 跑一遍基线，避免凭感觉改代码。当时最大的瓶颈是首屏图片和一个未拆分的巨型 JS bundle。

图片

  • 统一转 WebP/AVIF，体积平均减少 40%；
  • 懒加载非首屏图片，配合 srcset 做响应式尺寸；
  • 图标全部内联为 SVG，告别小图标请求。

资源与渲染

路由级代码分割把首包砍到原来的三分之一；字体用 font-display: swap；对长列表上虚拟滚动。最终 LCP 从 8s 降到 1.2s，性能分从 52 涨到 94。

JavaScript 异步编程演进史：从回调到 async/await
▾
📅 2026-07-30 JavaScript
回调地狱、Promise 链式调用、Generator 协程，再到今天写起来像同步代码的 async/await。

最早处理异步只能靠回调，多层嵌套形成的"回调地狱"让错误处理和代码阅读都变成噩梦。Promise 用扁平化的 .then().catch() 链解决了嵌套问题，但本质仍是函数拼接。

Generator 让函数可以暂停与恢复，配合运行器一度让异步代码能以同步的形态书写；最终 ES2017 的 async/await 把这套机制标准化，成为今天的默认写法。

理解这条演进线的关键，是理解事件循环：宏任务与微任务的调度顺序，决定了 await 之后的代码何时执行。工具会变，底层模型不会。

从零搭建一个个人导航页
▾
📅 2026-07-18 随笔
一个 HTML 文件、零构建、零依赖，加上时钟、天气和常用站点卡片，个人导航也可以很精致。

起因很简单：浏览器默认页太无聊，而现成的导航站塞满了广告。自己写一个，想要什么卡片就放什么。

技术选型刻意保持克制：单文件 HTML + 原生 JS，不引入框架，双击即可打开，扔到任何静态托管上就能跑。玻璃拟态卡片负责颜值，实时时钟和访客统计让页面有"活着"的感觉。

唯一的麻烦是第三方免费 API 不稳定，解决办法是为每个请求设置超时并准备备用接口，加载失败时给出友好提示，而不是让页面一直转圈。

浏览器开发者工具的 10 个冷门技巧
▾
📅 2026-07-02 调试
console.table、条件断点、日志断点、网络节流……用好 DevTools 能省掉大量 console.log。
  • console.table(arr) 把对象数组打印成表格；
  • 控制台输入 $_ 拿到上一个表达式结果，$0 是当前选中的元素；
  • 右键行号选 Add conditional breakpoint，条件成立才中断；
  • Add logpoint 可以不修改源码插入日志；
  • Network 面板可模拟弱网与离线；
  • Elements 中颜色小方块点击可在 HEX/RGB/HSL 间切换；
  • Coverage 面板找出未使用的 JS/CSS；
  • Performance 录制定位长任务；
  • Application 面板一键清理站点数据；
  • Ctrl+Shift+P 打开命令菜单，所有功能都能搜索执行。
